# קייטנת פליפר רעננה — הלו"ז היומי

אפליקציית ווב רספונסיבית להורי הקייטנה: מה הילדים עושים עכשיו, מה מחכה בהמשך היום, והודעות חשובות.

## מחזורים

המערכת מנהלת כמה מחזורי קייטנה במקביל, כל אחד והגיליון שלו (`js/config.js` → `CYCLES`).
המחזור הפעיל נבחר אוטומטית לפי התאריך; מחזור שהסתיים נשאר זמין בארכיון דרך `?cycle=1`.
נתוני הנוכחות נשמרים לפי תאריך, אז מחזורים לא דורסים זה את זה.

**להוספת מחזור:** שורה חדשה ב-`CYCLES` עם מזהה הגיליון, תאריכי ההתחלה והסיום ומזהי הקורסים בטאזמן.

## איך זה עובד

- **מקור האמת: הגיליון בגוגל.** האפליקציה מושכת את ה-xlsx ישירות מהדפדפן, מפענחת תאים ממוזגים וטווחי שעות מפורשים בטקסט, ומתעדכנת אוטומטית כל 5 דקות ובכל פתיחה.
- **בלי שרת ובלי build.** סטטי לגמרי: HTML + CSS + JavaScript (מודולים). פענוח ה-zip נעשה עם DecompressionStream המובנה בדפדפן.
- **שרשרת גיבויים:** גיליון חי ← מטמון מקומי במכשיר ← `data/fallback.json` הארוז באתר.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` + `js/app.js` | האפליקציה להורים |
| `admin.html` | מסך ניהול: הוראות עדכון + בדיקת תקינות הלו"ז |
| `js/parser.js` | הפרסר המשותף (דפדפן + Node) של ה-xlsx |
| `js/data.js` | משיכה חיה, unzip, מטמון, שעון ישראל |
| `js/icons.js` | אייקונים מצוירים, צבעי קטגוריות וקבוצות |
| `tools/build_fallback.mjs` | רענון `data/fallback.json` מהגיליון: `node tools/build_fallback.mjs` |

## עדכון הלו"ז וההודעות

הכול בגיליון, בלי לגעת בקוד. ההוראות המלאות בעמוד `admin.html`, כולל פורמט טאב `הודעות` לפס ההודעות הרץ.

## פיתוח מקומי

```bash
npx http-server . -p 8642 -c-1
```
